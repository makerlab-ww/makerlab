# 02. 화면 구성과 마우스 조작

## 학습 목표

- 마우스로 화면을 회전하고 이동하고 확대/축소할 수 있습니다.

### (1) 작업 화면의 구성

- **응용프로그램 막대:** 화면 맨 위에 있습니다. 파일 열기와 저장, 실행 취소 같은 기본 기능이 있습니다.
- **도구 모음:** 작업 공간을 고르고 도구 아이콘을 누르는 곳입니다.
- **브라우저:** 화면 왼쪽에 있습니다. 문서 안의 부품과 스케치 목록을 보여 줍니다.
- **캔버스:** 화면 가운데의 작업 영역입니다. 모델을 만들고 확인하는 곳입니다.
- **뷰큐브:** 화면 오른쪽 위에 있습니다. 보는 방향을 바꿀 수 있습니다.

- **타임라인:** 화면 아래에 있습니다. 작업한 순서가 기록됩니다. 자세한 사용법은 14절에서 다룹니다.

### (2) 마우스 조작
- **휠 굴리기:** 화면을 확대하거나 축소합니다.
- **휠을 누른 채 끌기:** 화면을 이동합니다.
- **Shift 키와 휠을 누른 채 끌기:** 화면을 회전합니다.
- **왼쪽 버튼 클릭:** 대상을 선택합니다.
- **오른쪽 버튼 클릭:** 메뉴를 엽니다.
